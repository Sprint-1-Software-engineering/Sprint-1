## Peer review

Every PR needs a reviewer other than its author. The reviewer checks the Issue criteria, scope, document links and API impact. API changes should include a QA review. Review is recorded with GitHub's review action, not just a merge or a chat message.

The person marked A in RACI is not automatically the PR reviewer. Planned reviewers may change with availability.

Actual work and evidence belong in [CONTRIBUTIONS.md](../CONTRIBUTIONS.md).
